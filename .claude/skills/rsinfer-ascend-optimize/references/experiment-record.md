# Ascend 对照实验记录

在本次实验的运行目录保存契约、原始数据与命令。需要提交结论时，沿用仓库 `doc/rsi/` 的记录方式。纯估算、单算子和服务实验填写与目标相关的项目。

## 测量前固定

| 项 | 本轮值 |
| --- | --- |
| 目标和约束 | 主指标与方向、目标 SLO、显存限制、正确性标准、实验预算 |
| 基线 | Git revision、实际引擎 identity、配置、checkpoint revision、权重/激活/KV 精度 |
| 平台 | SoC、物理 die、驱动、CANN 与 OPP、torch_npu、通信拓扑和 TP/EP/DP |
| 工作负载 | 数据集和输入版本、tokenizer/模板、实际 token IDs 或生成方式、到达/并发、采样和长度 |
| 执行路径 | ACL Graph 桶、eager、MTP、调度预算、KV 页/状态配置、冷/暖前缀及缓存 salt 策略 |
| 测量与验收 | 复现命令、预热、次数、计时边界、基线波动、有效 token 口径、精度检查及允许的变更范围 |

把 benchmark、正确性检查和输入生成器固定到同一版本。若任务需要改变口径，记录原因，并用新口径重跑基线。
