# GLM-5.3-Flash 原生执行优化记录

分支 `dev/ascend_a3_gg`，Ascend 910C，CANN 9.2.0，PyTorch 2.10.0，`torch_npu` 2.10.0.post7，权重 `/local/models/GLM-5.3-Flash-w8a8`。原生 worker 由 RSInfer 调度、分配和更新状态，算子复用 CANN、FLA-NPU 和 vLLM Ascend 中的实现。

后续实现了调度域独立推进，并继续验证 MLA 与 MTP 优化。同一 16K / 60K 协议实测 103.55 / 153.75 tok/s。 [后续 RSI 迭代记录](2026-11-26-glm53-native-rsi-iter.md)

## 对照基线

使用本机 `glm_53_flash_opt` 的 AISBench 流程。沿用固定种子的 GSM8K 样本，每次运行使用独立的请求标签和缓存盐。每组 16 条请求，四并发，流式生成 128 token。16K 和 60K 表示 16,384 和 61,440 个提示词正文 token。60K 组预热 55,296-token 共享前缀，另跑六项精度检查。吞吐按成功请求实际生成的 token 计。

| vLLM Ascend，DP2 × TP8，EP16，MTP5 | 输出 tok/s | TTFT 均值 / P90（ms） | TPOT 均值 / P90（ms） |
| --- | ---: | ---: | ---: |
| 16K | 79.9364 | 2588.3 / 3278.4 | 29.4 / 34.4 |
| 60K | 110.3326 | 1348.3 / 2325.5 | 23.4 / 27.4 |

基线两组各完成 16/16，精度 6/6。vLLM 的 16K 逐请求命中为 0，60K 为 49,536–54,144 token。原生使用同一单次预热流程，60K 每条实测命中 55,296 token。比较暖组吞吐和时延时需计入这个实际命中差异。启动与 MemCache 测量见 [Ascend 910C 部署与 RSI 实测](2026-11-26-ascend-a3.md)。本机原始数据见 [summary.csv](../../../ascend-a3-results/2026-11-26/glm-8192-32/summary.csv)。

## 完整模型 MemCache 跨重启

完整 45 层、TP8、MTP3 的实例先按原精度脚本通过 6/6，再用另一条 8,296-token 请求和独立缓存盐写出前缀。`cache-save` 排空后提交，控制面 PID 从 2311876 变为 2322024，外部 MemCache 池 PID 2268032 保持不变。使用同一 `--run` 和 `--prefix-manifest` 重启到 API 就绪耗时 92.160 秒。

全部 8 个 worker 的 PID 都改变。旧 worker 各写 195 个对象，新 worker 各取回 195 个对象。各 rank 读取耗时为 0.104–0.119 秒。池侧成功 GET 增加 1,560，成功 BatchGet 增加 56，GET 失败和缺失均为 0。重启后首条回放命中 8,192/8,296 token，生成 33 token，包含完整的 `NEEDLE-7492-ALPHA`。最终文本和推理文本与重启前一致。换盐后同样输出，命中为 0。回放请求总时延 3.583 秒，包含新进程的首轮算子派发和生成过程。外部对象读取发生在服务就绪前，后续请求从已导入的本地 radix 页读取。 [worker PID 和传输记录](../../../ascend-a3-results/2026-11-26/glm-native-mtp3-tp8/cache-proof/workers.csv) · [前后请求数据及池指标](../../../ascend-a3-results/2026-11-26/glm-native-mtp3-tp8/cache-proof)

整机复测使用 DP2 × TP8、每域 EP8、grouped GEMM、AI_CPU HCCL 和 MTP4。冷启动耗时 98.934 秒。保存后，同一运行目录启动到就绪耗时 95.479 秒。16 个 worker PID 全部变更，外部池 PID 2268032 及进程启动时间均保持。前缀由第一个调度域持有，8 个 rank 分别写入及恢复 17 个对象，读取耗时 0.088–0.104 秒。第二域没有该前缀。池侧增加 136 次成功 GET 和 16 次成功 BatchGet，两类失败次数均无增量。首条回放命中 2,048/2,073 token，生成的 22 token、最终答案及推理文本均与冷请求一致，换盐后命中 0。 [启动日志](../../../ascend-a3-results/2026-11-26/glm-native-final-dp2-tp8.log) · [PID、池指标和回放请求](../../../ascend-a3-results/2026-11-26/glm-native-final-dp2-tp8/cache-proof)
